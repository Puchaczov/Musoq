## Conflict decisions and evidence

### REC-140-C01 / REC-086-BINARY-001

The normative text says `until` consumes the delimiter and advances past it,
while the example placed `literal ': '` after `until ':'`. The original fixture
proves `key:: value\\n` succeeds and the natural `key: value\\n` fails at the
following literal. The approved target-local correction changes only that
literal to `literal ' '`. The corrected fixture then proves one colon and one
space parse successfully.

### REC-140-C02 / REC-086-BINARY-002

The CHECK example referenced `Data` from `Checksum` before declaring `Data`,
while the same specification says forward references MUST NOT occur. The
original fixture proves the example is rejected at Parse with
`MQ2030_UnsupportedSyntax` over `Data`, before code generation. The approved
target-local correction moves `Data` before `Checksum`; the corrected fixture
proves the reordered example analyzes without errors.

### REC-140-C03 control

The schema-reference example retains the independent definition-before-use
boundary: `Triangle` before `Point` remains a negative control, while `Point`
before `Triangle` remains valid.

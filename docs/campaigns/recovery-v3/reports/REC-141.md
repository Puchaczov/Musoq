## Documentation conflicts resolved

Eight target-local conflicts were reproduced and retained as permanent
controls:

- PNG byte-list validation uses magic, not a check Boolean expression.
- Apache until consumes its delimiter; redundant literals were removed.
- Apache timestamps are parsed before MaxDateTime.
- The mixed-protocol sync word is ushort, matching 0xAA55.
- The COBOL date uses the bound ToDateTimeWithFormat callable.
- SubRecord is declared before StorageRecord.
- The storage DataOffset is explicitly converted to the int required by
  InterpretAt.
- The all-types TABLE example explicitly projects all 20 columns because
  star expansion omits non-primitive/complex columns.

The original forms remain in the permanent test source where they are needed
as negative controls. The corrected forms are the target-local specification
examples and are executed against explicit repository-owned fixtures.

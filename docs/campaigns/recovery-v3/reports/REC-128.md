## Initial observations and finding

The preserved pre-repair replay is
`.campaign-artifacts/REC-128-focused-initial-r4`. It passed 37/48 and exposed
11 failures:

- async `GetAsyncEnumerator` failures escaped as raw exceptions because
  enumerator creation was outside the read envelope;
- eight read-plus-cleanup cases retained the primary MQ7011 but omitted a
  safe related-cause fact;
- regular async cleanup failure translated a canceled token into MQ7012.

REC-128-F01 is a confirmed production defect. The repair moves async enumerator
creation inside the MQ7011 boundary, records only the related exception type on
the primary lifecycle diagnostic, preserves cancellation precedence, and avoids
cleanup when no enumerator was created.

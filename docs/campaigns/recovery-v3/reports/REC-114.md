# REC-114 — Binary/text declarations versus malformed input data

## Outcome

REC-114 completed with the final revision-2 48-case binary/text recovery
matrix. It contains eight six-case families: 32 invalid mutations and 16
valid ordinary controls. Schema declarations and substrate data are mutated
independently. Schema mutations require located `MQ400x`/`MQ401x` diagnostics;
valid schemas with malformed bytes or text require structured `ISE` runtime
failures. No schema candidate was accepted merely because a tolerant
interpretation could return `NULL`.

The schema families cover multi-byte endianness, fixed sizes, text switch
defaults, escaped modifiers, switch selector/alias/label references and
branch ordering. The substrate families cover truncated values, validation,
encoding, negative sizes and positions, text pattern/literal/delimiter/
fixed-width failures, and valid controls. Repetition and substream families
cover zero progress, partial elements, exact under-consumption, bounded
overread, negative lengths, and exact/lax cursor resumption.

## Contract correction

Revision 1 is preserved as the initial frozen matrix. Its first replay showed
that F04's `repeat optional literal` declaration was rejected by the current
text grammar, so the intended zero-progress runtime condition was not reached
from a valid seed. The correction artifact records that observation. Revision
2 changes only F04 to the existing valid `Empty` schema reference repeated by
`Container`; an empty seed remains valid and one-character input reaches the
same expected `ISE0009` progress guard. No candidate was removed, weakened or
reclassified.

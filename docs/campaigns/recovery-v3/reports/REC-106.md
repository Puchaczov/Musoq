## Findings and repair

Three deterministic parser defects were found and repaired without changing
the frozen contract:

1. REC-106-F04 deleted the closing parenthesis from an empty source-method
   argument list. Both argument composers now recognize EOF as an unclosed
   function call boundary, producing MQ2021_UnclosedFunctionCall instead of a
   generic MQ2001_UnexpectedToken.
2. REC-106-P02 removed the left operand before `=`. The base-expression path
   now emits MQ2020_MissingOperand for the equality token. The guard is limited
   to `=` so the established keyword-predicate recovery behavior for LIKE,
   IS, IN, BETWEEN and related operators is unchanged.
3. REC-106-G04 removed every GROUP BY expression while retaining HAVING. The
   query-clause path now emits MQ2006_MissingGroupByColumn through the shared
   parser diagnostic factory.

The three existing evaluator assertions for an unclosed empty schema-method
call were updated to the more specific catalog diagnostic MQ2021. No row
values, provider metadata or generated-code output were used to infer a
syntax result. The frozen case contract and pre-observation manifest were not
edited after observation.

# REC-133 — Cancellation and bounded zero-progress behavior

## Outcome

REC-133 passed its frozen 48-case matrix and the complete eight-target Release
gate. No production finding was confirmed, so no production repair was needed.

The fixture uses the actual InstanceCreator compilation contract,
CompiledQuery.Run(CancellationToken), generated binary interpreters and
DiagnosticChunkedRowSource. It does not claim a product-level timeout setting.

## Matrix

The permanent matrix is split into four 12-case families:

- CC-01..CC-12: pre-cancelled compilation is rejected before provider entry.
- EX-01..EX-12: a controlled provider produces one row, execution is
  cancelled, and the producer is released and observed to exit.
- ZP-01..ZP-12: zero-length EOF elements and 10,001-byte condition repeats
  raise the generated interpreter's ISE0009 boundary.
- CL-01..CL-12: partial consumer disposal and finite producer completion are
  checked separately.

Every asynchronous case uses WaitAsync(TimeSpan.FromSeconds(2)). A budget
expiry calls Assert.Fail with HARNESS_TIMEOUT; it is not converted to a
diagnostic pass. The minimized partial-work reproduction is the owned
controlled provider in the permanent fixture. The minimized interpreter
reproductions are a zero-byte element and a 10,001-byte bounded repeat.

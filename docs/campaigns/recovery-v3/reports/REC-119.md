## Production finding and fix

- `AnalyzeCase` previously treated a statically evaluated non-boolean value as
  an unreachable false branch and did not report a final `CASE ELSE` after a
  proven-true condition. The analyzer now proves only boolean values, keeps
  literal-NULL and other non-boolean alternatives quiet, and reports the final
  unreachable `ELSE` once. The permanent matrix and adjacent evaluator tests
  cover both boundaries.

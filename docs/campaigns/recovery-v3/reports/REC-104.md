# REC-104 — Enum metadata propagation through query composition

## Outcome

REC-104 passed. The frozen matrix executed 48/48 candidate cases, with 32
compatible compositions, 8 warm replays and 8 invalid compositions. The test
class also passed 2/2 validation controls and 1/1 matrix check: 51/51 total,
with no failures or skips. The case contract remained frozen at revision 1 and
verified successfully.

## Contract coverage

The matrix covered eight cases each for CTEs, derived tables, joins/grouping,
set operations, identity conflicts and warm compilation. Compatible paths
retained the native `REC104PrimaryStatus` descriptor, its `short` carrier and
its fingerprint through aliases, composition and lowering. Nullable paths
retained nullable `short` carriers without erasing nominal identity. Warm
replays compiled against reversed controlled fixture order and retained the
same descriptor fingerprint, display name and underlying kind.

The eight invalid cases produced one root Bind diagnostic each: seven
`MQ3109_EnumIdentityMismatch` diagnostics for same-carrier, different-identity
operands and one `MQ3110_UnsupportedEnumOperator` diagnostic for an enum versus
ordinary numeric carrier. Every invalid case asserted its original conflicting
SQL span and actionable guidance. No generated-code or internal-compiler error
was emitted, and no row values were inspected to infer enum identity.

## Findings and repair

The campaign reproduced a metadata-loss boundary in query composition. CTE and
in-memory source alias propagation could discard enum descriptors; set
operation output schemas and generated row shapes did not consistently carry
nominal identity or nullable source-read metadata; aggregate and null-extended
shapes could lose the descriptor at lowering; and rewritten subquery
diagnostics could lose their original query span. Chained streaming set
operations also needed collision-aware arm names when source aliases repeat.

The production repair keeps enum descriptors and source-read metadata in the
logical output schema and generated shapes, reconciles compatible set arms by
descriptor identity rather than carrier equality, lifts nullable enum carriers
without changing identity, and reports incompatible operands at the owning
Bind span. The source-binding change is limited to enum-bearing schemas and
first-writer alias preservation, so ordinary CTE shape snapshots and recursive
CTE source aliases retain their established behavior. No interpretation-schema
syntax or row-inference fallback was introduced.

# REC-105 — Enum-specific mistake recovery and interpretation exclusion

## Outcome

REC-105 passed. The frozen matrix executed 48/48 candidate cases: 16 enum-name
cases, 12 enum-member cases, and 20 operator/output-rule cases. The complete
REC-105 test selection passed 64/64, with no skips or failures. The case
contract remained frozen at revision 1 and verified successfully.

## Contract coverage

The enum-name family passed 16/16: nine invalid names retained one expected
root metadata diagnostic (eight `MQ3005_TypeMismatch` and one
`MQ3107_UnknownEnumType`), while seven valid local/native names preserved the
declared enum metadata. Local names remained case-insensitive; native enum
references required the exact qualified CLR name, including nullable forms.

The enum-member family passed 12/12. All twelve unknown or mis-cased members
produced `MQ3108_UnknownEnumMember` in Bind, covering equality, inequality,
distinctness, membership, CASE and flags. The operator/output family passed
20/20: nineteen unsupported enum operations produced
`MQ3110_UnsupportedEnumOperator`, and the enum script-parameter case produced
`MQ3112_UnsupportedEnumScriptParameter`. Explicit `EnumValue`/`EnumName`
bridges and enum partition keys remained valid.

The interpretation boundary controls passed 8/8. Binary interpretation
references used the existing `MQ2030_UnsupportedSyntax` path for the tested
unsupported shape, text references used `MQ4003_UndefinedSchemaReference`,
and direct `enum`/`flags` annotation spellings remained
`MQ2001_UnexpectedToken`. No logical enum descriptor was created by an
interpretation field, and TABLE enum syntax remained a separate contract.
No row value was inspected to infer enum identity, and no production repair
was required.

## Findings and repair

REC-105 found no production defect within its bounded enum recovery contract.
The work adds explicit evaluator coverage for remaining name, member,
operator, output and script-parameter mistakes, plus parser/visitor controls
that prevent TABLE enum support from expanding binary/text interpretation
syntax. Invalid semantic candidates asserted one Bind root diagnostic and
actionable guidance. Eight metadata failures also emit the known
`MQ3001_UnknownColumn` projection cascade after the primary type failure; it
was counted as an expected cascade, not an additional root diagnostic. No
`MQ9001_InternalCompilerError` or `MQ8001_CodeGenerationFailed` occurred.

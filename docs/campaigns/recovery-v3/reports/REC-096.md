## Production correction

`ErrorCatalog.GetDidYouMeanCandidates` now uses `StringComparer.Ordinal` for
candidate identity. It still computes the closest spelling using invariant
case transformation, but no longer silently drops distinct exact values such
as `Name` and `name`. Tied candidates remain guidance only, so no arbitrary
automatic edit is emitted.

# REC-137 — Cold/warm cache and schema-change diagnostics

## Outcome

REC-137 passed its frozen 48-case cache/diagnostic matrix, adjacent cache and
state regressions, and the complete eight-target Release gate. No production
code was changed. The fixture establishes that warm and canonical reuse remain
truthful for the current provider binding, that changed semantic schema facts
do not inherit old success or diagnostics, and that stale enum execution asks
for recompilation instead of fabricating a syntax failure.

The permanent fixture is
`DiagnosticRec137ColdWarmCacheDiagnosticsTests`. It clears only the
test-owned process caches at setup/cleanup; it does not purge user caches or
external state.

## Matrix and observations

The frozen contract contains four 12-case families:

- `COLD-01..COLD-12`: cold, warm, changed-schema and restored-schema
  compilations of the same query text. A changed schema that removes `Name`
  produces the current `MQ3001_UnknownColumn`; the restored state succeeds.
- `SEQUENCE-01..SEQUENCE-12`: the same `Extra` query transitions invalid →
  valid → invalid as the provider contract changes. The valid middle state
  succeeds and both invalid states retain their current source span and
  unknown-column diagnostic.
- `ENUM-01..ENUM-12`: the same query is compiled with two enum descriptor
  fingerprints. The second artifact is rebuilt, and running the first compiled
  query after descriptor drift produces the explicit `recompile the query`
  compatibility outcome.
- `SETTINGS-01..SETTINGS-12`: source-runtime resolver values and source
  metadata versions change between compilations. The second run sees the new
  token and metadata, and declared settings remain outside reusable execution
  compilation.

Calibration failures are retained. Early failures were fixture compilation,
missing enum capability, an advertised-but-unimplemented query-scoped source,
an intermediate capability shape, expected-value mismatches and a disposed
compiled query. The remaining warm-path assertion was intentionally relaxed
only after telemetry showed a valid distinction: COLD-02 used
`canonical-hit`, which reuses a structurally equivalent artifact and rebinds
the current provider but does not set the exact-cache `StopAfterPlanning` flag.
The observable output and changed-schema diagnostic were correct. This is not
recorded as a production finding.

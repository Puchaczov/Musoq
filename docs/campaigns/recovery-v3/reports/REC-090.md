# REC-090 — Exact quick-fix targeting in repeated and nested text

REC-090 verifies that an emitted alias quick-fix changes only the erroneous
qualified reference and leaves repeated spellings in strings, comments,
surrounding SQL, and other scopes untouched.

## Frozen candidate matrix

The final candidate set contains 48 structurally distinct cases, registered in
`evidence/REC-090-pre-observation-manifest.json` and linked by
`evidence/REC-090-case-contract.json`. The source-backed matrix is divided
into 12 repeated-string/comment cases, 12 projection-expression cases, 12
predicate/result-clause cases, and 12 nested-scope/subquery cases. The frozen
malformed form contains one `peple` alias binding fault and the valid seed is
the corresponding `people` query in the test corpus.

The initial 48-pass run was implementation feedback before the expectation
manifest was frozen and is explicitly excluded from candidate counts. The
final replay ran after the freeze against the unchanged candidate source.

## Repair contract and result

All 48 final candidates passed with one `MQ3015_UnknownAlias` Bind envelope,
one QuickFix action, the exact expected source span, and replacement text
`people`. The test applies the returned `TextEdit` from the envelope itself;
it does not implement a global string replacement applier.

For every case, the repaired document was compared byte-for-byte with the
expected document, recompiled, executed against the repository-owned
`#test.people()` fixture, and required to produce rows. This proves the
intended error disappears while the repeated non-executable occurrences and
surrounding text remain unchanged.

Focused final replay: 48 passed, 0 skipped, 0 failed.

Adjacent symbol and named-argument diagnostic suites: 30 passed, 0 skipped,
0 failed.

Campaign tool tests: 46 passed, 0 skipped, 0 failed.

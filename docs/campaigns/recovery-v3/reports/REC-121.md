The source-unit contract is UTF-16 code units with one-based line and column
values on the structured surfaces. LF, CRLF, mixed and lone-CR endings are
resolved as logical lines; zero-length EOF spans remain known insertion points.
Terminal rendering is separate: tabs expand to four-column stops, combining
marks consume no display cell, wide Unicode scalars consume two cells, and
non-tab control characters are escaped. JSON ranges remain zero-based line and
character values derived from the structured source coordinates.

## Initial finding and repair

The first executable replay passed 38/49 tests and failed the eleven display
cases D01, D02, D04–D12. It exposed one production defect in
`DiagnosticFormatter`: raw tabs and controls were emitted into terminal
snippets, and caret placement used UTF-16 source columns rather than terminal
display cells. D03 passed because the tested supplementary glyph happened to
have coincident source and display placement.

The bounded production correction keeps `ContextSnippet` raw for structured
consumers, removes the embedded raw pointer line from terminal presentation,
expands tabs, escapes controls, measures combining marks and wide Unicode
scalars, and computes caret start and length in display cells. The final
focused replay passed 49/49 without changing the frozen oracle.

# REC-136 — Supported concurrent-session diagnostic isolation

## Outcome

REC-136 passed its frozen 60-case concurrent-session matrix, the adjacent
Evaluator regressions and the complete eight-target Release gate. The scope
found no production defect and made no production-code change. It establishes
the supported boundary: independent query sessions may execute concurrently
with isolated runtime state. It does not authorize arbitrary concurrent reuse
of mutable engine objects.

The permanent fixture is
`DiagnosticRec136ConcurrentSessionIsolationTests`. MSTest does not schedule
the class in parallel because the historical test base controls process/thread
culture and shared test compilation coordination. Each test method nevertheless
creates independent production sessions and executes those sessions
concurrently. That distinction is the central REC-136 result.

## Matrix and observations

The frozen contract contains five 12-case families:

- `PROVIDER-01..PROVIDER-12`: identical query text with distinct provider
  schemas and row values.
- `CONTEXT-01..CONTEXT-12`: distinct runtime parameter snapshots; source
  settings are exercised as a supporting control in the same test method.
- `DIAG-01..DIAG-12`: distinct unknown-column markers, source spans and
  compiler correlation contexts.
- `ENUM-01..ENUM-12`: distinct query-local enum names and metadata
  fingerprints.
- `STAR-01..STAR-12`: the historical full-star modifier query with distinct
  projected values, exclusion and rename behavior.

The first calibration exposed an incorrect test oracle: the historical `LIKE`
star projection intentionally did not include `Name`. A no-build replay then
confirmed the old stale binary. Both failures are preserved as calibration
artifacts. The oracle was corrected to assert a unique projected `Money` value,
the focused binaries were rebuilt, and the calibration and authoritative
replays passed. No frozen expectation was replaced.

The passing observations establish that concurrent sessions retain their own
rows, schema bindings, parameter snapshots, source-setting values, diagnostic
markers and locations, internal correlation IDs and query-local enum
descriptors. The historical star modifier remains covered while its
`DoNotParallelize` attribute is classified as test-harness global state rather
than a production concurrency restriction.

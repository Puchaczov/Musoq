# REC-113 — Semantic mutations in grouping, windows, sets and recursion

## Outcome

REC-113 completed with a passing 48-case semantic mutation matrix. The matrix
contains eight six-case families: 32 invalid mutations and 16 valid ordinary
controls. Every invalid candidate starts from an independently analyzed valid
seed, asserts its exact Bind diagnostic code and envelope, and rejects the
forbidden internal fallback codes. Every valid control remains successful.

The matrix covers grouped-column and grouping-index errors, aggregate use in
GROUP BY, window order/frame/filter rules, set cardinality and type rules,
recursive CTE shape and reference restrictions, QUALIFY and aggregate filter
visibility, normalization of nested set/group/window/recursive failures, and
result-level ordering context.

## Semantic and normalization checks

The five normalized failures G01-G05 stop before logical and physical plans
are produced. Their expected set cardinality, set type, grouping, window-frame
and recursive output-shape diagnostics remain visible at the semantic
boundary, with no `MQ8001`, `MQ9001` or `MQ9002` fallback.

The ownership assertion keeps `MQ3034_AmbiguousAggregateOwner` distinct from
`MQ3012_NonAggregateInSelect` for an ambiguous aggregate callable. A valid
grouped query with HAVING, result-level ordering, SKIP and TAKE remains valid,
which preserves the result-context boundary independently of aggregate-owner
failure.

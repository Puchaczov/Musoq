# REC-139 — Generated-code and incompatible-artifact recovery

## Outcome

REC-139 passed its frozen 24-case generated-artifact recovery matrix, adjacent
converter and parser regressions, campaign-tool self-tests, and the complete
eight-target Release gate. No production code was changed. The permanent
fixture covers generated compiler failures, incompatible cached artifacts,
safe internal-failure envelopes, and early rejection of already-known invalid
queries.

The evidence is limited to engine-owned converter/parser diagnostic boundaries.
It does not claim installed CLI, host/product, human-workflow, AI-agent or
universal conformance.

## Matrix and observations

The frozen contract contains four six-case families:

- `GEN-MAPPED-01..GEN-MAPPED-03` and `GEN-UNMAPPED-01..GEN-UNMAPPED-03`:
  generated C# failures preserved `MQ8001_CodeGenerationFailed`, target-native
  compiler codes and generated-source facts. Exact mapped locations remained
  generated coordinates even when their offsets exceeded SQL length; unmapped
  cases remained unknown. No location was clamped to the SQL document.
- `ART-01..ART-06`: format-version, engine-version, compilation-options,
  Runtime V2 contract, execution-semantics and strict generated-code-hash
  incompatibilities all returned `MQ8002_CompiledArtifactIncompatible` with
  runtime artifact classification and explicit recompile guidance.
- `INT-01..INT-06`: compiler exception shapes returned
  `MQ9001_InternalCompilerError` with safe correlation identifiers. Native
  messages, source paths and nested details were absent from default text and
  JSON; only safe mapped spans and structured facts were retained.
- `EARLY-01..EARLY-06`: the known-invalid query set stopped at
  `MQ2005_InvalidSelectList` or `MQ3001_UnknownColumn` during Parse/Bind before
  generated recovery, artifact incompatibility or internal-failure handling.

The contract records fixture identity, mutation declarations, authority hashes
and expected classifications before observation. It was verified 24/24 before
and after the authoritative replay without expectation replacement.

Calibration failures are retained. The initial focused fixture compilation
stopped before test results because the test harness needed parser/compiler
imports and nullable generated-source path handling. Those corrections were
test-only; no production finding or repair was recorded. The post-calibration
authoritative replay passed all four focused methods.

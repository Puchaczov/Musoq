# REC-116 — Path, regex and glob warnings with quiet controls

## Outcome

REC-116 completed with the final revision-2 48-case advisory-precision
matrix: 19 valid ordinary controls and 29 valid suspicious cases, with no
invalid candidates. The matrix covers rooted and relative paths, raw and
doubled escapes, standalone escapes, regex word boundaries and character
classes, glob-like LIKE patterns, SQL wildcards, prose and dynamic operands.

Revision 1 remains immutable. Its first replay exposed two production
diagnostic findings and two invalid dynamic-operand fixtures. Revision 2
records only the valid-column fixture corrections for R07/L11 and the
authority-permitted MQ5014 phase metadata correction from Bind to Parse; no
warning code, candidate or expected classification was removed.

## Production findings and fixes

- A leading ordinary regex boundary (`\b` or preserved `\\b`) received an
  unrelated lexical MQ5014 path warning. Regex-aware suppression now removes
  that false positive while retaining the binding-specific MQ5015 warning.
  The same suppression is applied to syntax-only analysis and semantic-cache
  replay.
- LIKE advisory analysis warned for whitespace-containing prose such as
  `'* prose'`; whitespace is now a quiet control before glob classification.
- QueryAnalyzer now places warning-only parse diagnostics in the shared
  semantic context, matching the converter pipeline and allowing contextual
  suppression without changing authored literal values.

# REC-135 — Adversarial metadata and safe diagnostic rendering

## Outcome

REC-135 passed its frozen 48-case renderer-only matrix and the complete
eight-target Release gate. The matrix uses synthetic provider-controlled names
and descriptions containing terminal escapes, newlines, bidi controls, long
values and instruction-like text. It verifies that these values remain data in
diagnostic text, detailed text, direct envelopes, machine JSON and bounded
identifier suggestions.

The fixture is explicitly categorized `RendererOnlyNonAgentEvidence`. No AI
agent, shell actor, installed provider or external service was invoked. These
results therefore do not claim prompt-injection resistance or agent safety.

## Matrix and findings

The permanent matrix contains four 12-case families:

- `META-01..META-12`: hostile metadata through diagnostic text and detailed
  rendering.
- `JSON-01..JSON-12`: direct datasource envelopes through text and JSON
  serialization.
- `ID-01..ID-12`: hostile unknown-column candidates, bounded visibility and
  automatic-edit safety.
- `AGENT-01..AGENT-12`: renderer-only fixtures retaining instruction-like
  content as literal data for later live-agent work.

The first executable replay found raw terminal escapes, status-forging
newlines, unbounded context/metadata and raw identifier candidate facts. The
repair added shared display and JSON boundary handling, datasource envelope
isolation, safe detailed/context rendering, bounded identifier facts and safe
automatic-edit guards.

The first full gate then exposed a compatibility regression: datasource
sanitization converted absent optional snippets to empty strings. That failed
gate is preserved. Optional provider text now retains `null`, and the affected
Converter and Evaluator location contracts pass.

Findings resolved:

- `REC-135-F01` — public diagnostic/envelope sinks did not uniformly escape or
  bound hostile provider metadata.
- `REC-135-F02` — semantic candidate facts could retain raw provider-controlled
  identifier values.
- `REC-135-F03` — the initial envelope hardening changed nullable optional text
  semantics.

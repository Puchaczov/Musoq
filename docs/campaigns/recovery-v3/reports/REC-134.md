# REC-134 — Secret-safe diagnostics across all engine sinks

## Outcome

REC-134 passed its frozen 48-case matrix and the complete eight-target Release
gate. The matrix found a real public diagnostic leakage boundary: structured
diagnostic payloads and parser presentation surfaces could retain synthetic
secret sentinels. The repaired presentation boundary now redacts public sinks
while explicitly labeling trusted verbose output that may retain sensitive
details.

The fixture uses actual parser, evaluator, settings, binary interpretation,
logger and serialized-envelope paths. It uses only unique synthetic sentinels;
no credentials or complete process environments were used or persisted.

## Matrix

The permanent matrix is split into four 12-case families:

- PR-01..PR-12: provider exceptions, parameter binding, inner exceptions and
  substrate failures.
- SET-01..SET-12: actual runtime settings and safe DESC SETTINGS descriptions.
- SN-01..SN-12: unterminated string literals selected by diagnostic spans.
- LG-01..LG-12: binary interpretation substrate data and captured engine logs.

Each case checks the public exception and envelope surfaces, formatted text and
JSON, structured arguments, snippets, related locations, actions and captured
logs where applicable. Trusted verbose cases separately require the sentinel to
remain available only under an explicit \`Trusted verbose\` policy label.

## Findings and repair

The first executable replay passed 24/48. It showed that provider/parameter/
substrate envelope presentation and parser diagnostic formatting could expose
sentinels, while the settings and logging families were already safe. The
production repair added a shared presentation sanitizer, applied it to
diagnostics, formatters, envelopes, actions, related locations and span
selected snippets, and labeled explicit verbose details. It also corrected
trusted verbose fallback for top-level exceptions without inner exceptions.

The first full gate then exposed one compatibility regression: numeric source
text such as \`ulong\` was partially redacted as \`[redacted]ong\`. That failed
gate is preserved. Span redaction was narrowed to quoted/raw string literals;
the focused regression and final frozen matrix then passed.

No frozen expectation was replaced. The failed calibration TRXs and the failed
full-gate evaluator TRX remain under unique \`.campaign-artifacts\` directories.

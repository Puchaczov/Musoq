# REC-129 — User-owned runtime faults versus internal invariants

## Status

REC-129 is complete. The frozen 48-case classification contract was verified
before observation and again before completion. The final runtime matrix passed
48/48, all adjacent suites passed, and the authoritative Release gate passed
all 8/8 targets. No production finding was confirmed, so this scope adds
regression evidence without a production repair.

exception-type facts, null source positions for internal failures, and absence

remain MQ3095 at bind time. The seven data-dependent scalar cases remain MQ9002
at runtime. Six data-dependent arithmetic cases remain MQ9002, while two
constant division cases remain MQ3008 and four constant overflow cases remain
MQ3032 at bind time.

## Initial observations

Two preserved focused artifacts failed before the authority contract was frozen.
They exposed fixture calibration issues rather than production behavior: an
invalid join-shaped regex probe, two arithmetic probes whose data did not
trigger the intended runtime failures, and one scalar case whose expectation
needed to be runtime cardinality. A stale-binary replay retained the same
four failures. After correcting the fixture and oracle, the pre-freeze replay
passed 48/48; the contract was then frozen and the completion replay passed
48/48. The failed artifacts remain under unique campaign-artifact directories.

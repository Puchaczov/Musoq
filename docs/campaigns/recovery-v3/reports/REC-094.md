## Observation and correction

The first executable iteration was deliberately excluded from candidate
evidence: 27 passed, 2 failed, and 29 total. The two failures were W02 and
C02, where the current document already contained `Name`; applying the
captured replacement was idempotent, so the generic assertion that every
offset-only application must change the current text was invalid.

Revision 2 narrowed that demonstration assertion to cases where offset-only
application would alter current text. The stale rejection, reanalysis, native
boundary, and identity assertions were unchanged. The corrected source was
rebuilt before the final replay.

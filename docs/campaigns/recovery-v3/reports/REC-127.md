## Status

observation. The final provider-boundary matrix passed 50/50 tests, the

authoritative Release gate passed all 8/8 targets.

Each provider-failure case asserts the MQ7010 DataSource envelope, actual
schema/source/alias/context/operation facts, the original safe cause type and
absence of the provider's secret argument. E02 asserts MQ7003 and zero opens
for a missing required source parameter. The provider failures are also
checked not to enter the SQL syntax code range.

## Initial observations and finding

The preserved r3 replay exposed a fixture source-name defect before a valid
controlled replay; it remains under `.campaign-artifacts/REC-127-focused-initial-r3`.
After that fixture repair, the r4 replay observed MQ9001 for all construction,
description and planning provider faults. Open faults reached MQ7010 but the
safe envelope did not expose `causeType`; the valid-seed join assertion also
under-counted two source opens. These artifacts remain preserved and the
frozen contract was not changed.

REC-127-F01 is a confirmed production defect. Provider failures outside the
runtime row-source lifecycle escaped the datasource boundary and were
classified as internal compiler failures. The repair routes construction,
DescribeSource and TryPlanSource failures through MQ7010 with the actual
operation and original exception type, adds the safe cause fact to lifecycle
diagnostics, and retains the established QueryAnalyzer raw-provider rethrow
contract.

## Diagnostic and valid-neighbor evidence

All 24 candidate cases were novel, with zero duplicates, zero metamorphic
variants, and a clean streak of 24. The maximum-overflow and minimum-underflow
families each passed all eight backing types with exact `MQ2046` spans. The
literal family passed all eight cases: unsupported decimal backing emitted
`MQ2043`, missing/non-integral or decimal-suffix members emitted `MQ2044`,
and malformed hexadecimal, binary, octal, and base-suffix forms retained
`MQ1006`, `MQ1007`, and `MQ1008` as contracted.

Candidate code counts were `MQ2046`: 16, `MQ2043`: 1, `MQ2044`: 3,
`MQ1006`: 2, `MQ1007`: 1, and `MQ1008`: 1. Each candidate had one root
diagnostic, valid locations, a non-empty explanation and documentation
reference, suggested fixes, and no unexpected secondary diagnostic.

The valid controls confirmed all eight backing types at minimum, maximum and
zero; fitting suffix and hexadecimal/binary/octal values; flags with aliases
and a trailing comma; and an undeclared native `short` value of 99. The
runtime query returned short 99 for both value projections, `NULL` for
`EnumName`, `false` for `IsDefined`, no CLR `Enum` object, and preserved enum
type metadata. This directly demonstrates that `Enum.IsDefined` is not the
validity oracle for representable unknown values.

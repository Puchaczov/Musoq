# Musoq Core Engine 17.0.19

Stable patch release of the seven aligned .NET 10 packages: Musoq.Parser,
Musoq.Plugins, Musoq.Schema, Musoq.Evaluator, Musoq.Converter, Musoq.Formatter,
and Musoq.Benchmarks.Scenarios. Upgrade engine packages together.

## Query compilation and interpretation fixes

- Preserve column bindings and result shapes when wildcard projections, joins,
  CTEs and DISTINCT are composed.
- Correct inferred nullability for CASE expressions and interpreted records,
  including null predicates inside interpretation schemas.
- Support indexed source arguments and computed member access while preserving
  their types through planning and generated execution.
- Preserve scoped collection-source schemas and generic scalar bindings when
  interpreted values are combined with other query features.

Language and binary/text specifications clarify the corrected behavior. Regression
coverage exercises the combinations with typed, in-memory fixtures and an existing
provider binary. Query assertions and reference coverage have also been strengthened.

## Tooling

README benchmark comparison tooling supports reproducible comparisons of retained
campaigns. Existing chart points are preserved; this release does not introduce a
new Official benchmark campaign.

## Compatibility and downstream impact

Datasource public contracts remain unchanged. Stable packaging validates Schema
and Plugins against the preceding published same-major ABI baseline. Execution IR
remains 14, host ABI remains 10, and package format remains 2. Recompile persisted
queries affected by the corrected bindings and metadata.

Downstream hosts should align their engine packages to 17.0.19. Cloud's separately
qualified release will import the updated specifications and refresh its owned
documentation and package references.

## Qualification

Publication requires release-script checks, formatting, a Release solution build,
the complete Release test suite, seven-package packing with ABI checks, and
successful Windows/Linux branch CI for the exact release commit. GitHub assets
and all seven exact NuGet versions are verified after publication.

Local qualification passed: Release build with zero warnings and errors; 31,139
passed tests and four existing skips; release-script and formatting checks; all
seven packages packed with Schema/Plugins ABI validation against 17.0.18.

# Musoq Core Engine 17.0.18

Stable patch release of the seven aligned .NET 10 packages: Musoq.Parser,
Musoq.Plugins, Musoq.Schema, Musoq.Evaluator, Musoq.Converter, Musoq.Formatter,
and Musoq.Benchmarks.Scenarios. Upgrade engine packages together.

## Corrected result metadata

Ordered and window queries could return the correct primitive enum values while
omitting their portable enum descriptors from result columns. This was an engine
regression in the terminal-row reuse path introduced in 17.0.17; it does not require
datasource schema or row-contract changes.

Result-carrier selection now preserves the existing static column metadata
reference. Deferred result fallback uses the same complete column constructor as
other execution paths, retaining enum descriptors and source-read types.

Regression tests use in-memory native enum fixtures and cover ordering by a scalar
helper, aliased ordering keys, paging, and window results. Datasource qualification
also exercises the original OS, Archives and separated-values failures.

## Compatibility and downstream impact

Datasource public and binary contracts are unchanged. Execution IR remains 14,
host ABI remains 10, and package format remains 2. Recompile persisted queries
created with 17.0.17 to regenerate their result metadata. Downstream hosts and
datasources should align their engine dependencies to 17.0.18; Cloud/CLI manual
projections and releases are separate work.

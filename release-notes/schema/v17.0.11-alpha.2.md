# Musoq.Schema 17.0.11-alpha.2 - Structured Runtime Input Failures

This package carries typed runtime-input failure reasons and input positions through interpretation and datasource lifecycle diagnostics, and owns the provider-facing input diagnostic contract for runtime-v2 datasource plugins.

This prerelease is for:

- Musoq.Schema

## Highlights

- Mapped malformed runtime input to MQ7014 and interpretation failures to the MQ7101-MQ7115 diagnostic family.
- Added `Musoq.Schema.Diagnostics.DataSourceInputException` and its stable reason/location types so datasource plugins can report malformed input without referencing `Musoq.Parser`.
- Preserved byte and character offsets separately from SQL source locations.
- Kept ordinary messages safe while retaining controlled failure reasons and schema, source, and field context for diagnostics; Core adapts Schema failures to its existing Parser diagnostic representation internally.

## Compatibility

This alpha adds diagnostic properties to `DataSourceLifecycleException` and the Schema-owned datasource-input diagnostic contract. No datasource-provider interface or query-planning contract change is intended. Datasource-facing APIs use Schema/BCL types; Parser remains an internal Core diagnostic implementation detail.

## Manual impact

This schema package does not change CLI commands, service behavior, supported tool endpoints, MCP resources, or installer behavior. Manual impact is unchanged.

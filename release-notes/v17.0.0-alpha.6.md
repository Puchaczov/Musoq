# Musoq 17.0.0-alpha.6 - Diagnostic Command Preamble Support

This alpha release fixes SQL diagnostic command detection for runtime-v2 scripts that declare setup statements before `PROFILE` or `EXPLAIN ANALYZE`.

This is a full-train prerelease for:

- `Musoq.Parser`
- `Musoq.Plugins`
- `Musoq.Schema`
- `Musoq.Evaluator`
- `Musoq.Converter`

## Highlights

- `PROFILE ...` and `EXPLAIN ANALYZE ...` are now recognized after runtime-v2 setup statements such as `let`, `table`, `couple`, binary schema declarations, and text schema declarations.
- Diagnostic command execution preserves the setup statements when compiling the inner query, so script variables and source/table declarations remain available.
- Added classifier and execution regression coverage for diagnostic commands after runtime preambles.

## Compatibility

Public APIs and diagnostic output shapes are unchanged. SQL diagnostic commands still return the diagnostics text table with `LineNumber` and `Text` columns.

# Musoq 17.0.2-alpha.2 - Release Packaging Guardrails

This full-train alpha strengthens the release pipeline and package compatibility guarantees for the runtime-v2 architecture.

This prerelease is for:

- `Musoq.Parser`
- `Musoq.Plugins`
- `Musoq.Schema`
- `Musoq.Evaluator`
- `Musoq.Converter`

## Highlights

- Added same-major binary compatibility validation for the `Musoq.Plugins` and `Musoq.Schema` datasource ABI packages.
- Added release-script behavioral tests covering package registry validation, baseline selection, and command failure propagation.
- Marked test, benchmark, playground, and example datasource projects as non-packable so only registered release packages are produced.
- Extended release packaging guardrails to validate bundled assemblies, symbols, dependency graphs, and clean consumer restore behavior.

## Compatibility

This alpha contains release infrastructure and package validation improvements. The existing CSharpClr compilation and execution APIs remain unchanged.

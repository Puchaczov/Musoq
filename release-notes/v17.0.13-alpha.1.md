# Musoq 17.0.13-alpha.1 - binary interpretation and conformance

This full-train alpha releases `Musoq.Parser`, `Musoq.Plugins`, `Musoq.Schema`, `Musoq.Evaluator`, and `Musoq.Converter` at `17.0.13-alpha.1`. Changes are described relative to `v17.0.12-alpha.1`. The C# execution target remains bundled through `Musoq.Converter`; no standalone target package is introduced.

## Binary schema expressions and interpretation

- Preserve expression types and nullable values through binary schema arithmetic, comparisons, casts, `case` expressions, computed guards, and repeated conditions.
- Resolve nested, indexed, repeated, generic, and switch-selected fields with their element types and containing-record context, including parent and ancestor references.
- Keep byte and bit cursor alignment, checked size and position evaluation, and row-local property joins consistent across binary interpretation and generated query execution.
- Preserve null behavior for absent conditional records and nested members, and report invalid schema expressions and sizes through structured diagnostics.

## Conformance and documentation

- Add an in-process evaluator suite for 200 upstream-derived Kaitai cases, 204 SQL queries, and 47 fixture binaries. Expected values are independently asserted; the suite does not treat successful parsing alone as conformance.
- Expand the README with executable SQL examples for binary arrays, nested and tagged formats, tolerant interpretation, and file-search workflows.

## Compatibility

- No intentional public API or datasource provider contract break was identified in these changes. `BytesInterpreterBase<TOut>` adds the protected `ResolveExpressionSize<T>` helper; existing public and protected members are retained.
- Align all five Core package versions for this release. Upgrade the full train together to keep its parser, schema, evaluator, and converter behavior version-aligned.

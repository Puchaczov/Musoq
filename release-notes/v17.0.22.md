# Musoq Core Engine 17.0.22

Stable patch release of seven aligned .NET 10 packages. Upgrade Musoq.Parser,
Musoq.Plugins, Musoq.Schema, Musoq.Evaluator, Musoq.Converter, Musoq.Formatter,
and Musoq.Benchmarks.Scenarios together.

## Query correctness

- Preserve scan-specific entity types, column contracts, and projections when
  sibling queries reuse a datasource alias. Keep optional interpreted members
  nullable, bind compound grouping keys to the joined row, and distinguish a
  missing CTE row from a present row whose values are all NULL in FULL JOIN.
- Check generic scalar constraints against the inferred types. Bind applicable
  generic callables through a proven non-null strict cast and report invalid
  calls through the normal diagnostic path.
- Propagate typed NULL through radix conversions, byte conversions, and
  GetBytes string-slice bounds. Existing byte widths and range checks still
  apply. A bare NULL can require a type to resolve an overload.

## Interpretation and performance

- Keep binary payloads typed as byte arrays when CASE combines them with NULL,
  compatible byte arrays, or empty array literals. Use bound source aliases to
  identify truly duplicate CASE conditions.
- Provide clearer binary field offset and ORDER BY alias guidance. Report the
  operand types and source span for rejected operator combinations. Hosts can
  opt in to execution-scoped TryInterpret and TryParse observations with stable
  outcome codes.
- Use the generated comparer for full-record ordering. Repair sparse disorder
  within a bounded insertion budget, and reduce small top-record shifts and
  tolerant text parsing overhead.

## Benchmark tooling

Regenerate canonical logical and physical plans, Execution IR, and C# from the
actual benchmark compilation paths. Map changed snapshots to affected cases and
compare retained timing and allocation results when the workload, source
provenance, and measurement environment match. The Official catalog contains
279 cases.

## Compatibility and validation

The stable train keeps the datasource ABI, Execution IR version, host ABI
version, and persisted query format version. The release packer validates
Musoq.Schema and Musoq.Plugins against the published 17.0.21 baseline and
produces one NuGet package and one symbol package for each of the seven
packages.

The feature tree passed 31,501 Release tests with four existing refresh skips.
Release qualification checks the versioned candidate with the full Release
suite, the release package validator, and Windows and Linux CI on the tagged
source commit. The Official campaign for 17.0.22 follows publication.

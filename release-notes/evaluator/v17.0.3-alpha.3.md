# Musoq.Evaluator 17.0.3-alpha.3 - Runtime Cache Read Throughput

This package-specific alpha release improves evaluator hot-path throughput and records a reproducible performance baseline for representative runtime-v2 query shapes.

This prerelease is for:

- `Musoq.Evaluator`

## Highlights

- Removed read-side lock contention from bounded runtime caches by publishing immutable lookup snapshots while retaining synchronized insertion, bounded eviction, and explicit clearing.
- Removed read-side locking from weak type caches and made cache replacement atomic.
- Reduced repeated lookup and type-check overhead in dynamic nested-value access by using direct cached-accessor fast paths.
- Preserved dictionary, dynamic-object, indexed-path, missing-member, and cache-eviction behavior with focused regression coverage.
- Added generated performance samples and documented baselines for reflected joins, correlated subqueries, window/CTE/set operations, and table projection.

## Compatibility

This release does not intentionally change the public `Musoq.Evaluator` API. `Musoq.Evaluator` is released as `17.0.3-alpha.3`; Parser, Plugins, and Schema remain at `17.0.3-alpha.2`. A matching `Musoq.Converter` `17.0.3-alpha.3` package is released separately.

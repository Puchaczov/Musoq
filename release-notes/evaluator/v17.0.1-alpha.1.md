# Musoq.Evaluator 17.0.1-alpha.1 - Runtime V2 Finalization

This package-specific alpha release publishes the evaluator runtime-v2 finalization work without advancing unchanged packages in the train.

This prerelease is for:

- `Musoq.Evaluator`

## Highlights

- Completed runtime-v2 execution lowering cleanup around source, join, table-completion, final-sink, post-operation, and sidecar pipeline responsibilities.
- Added global sidecar CTE support coverage for cross/apply, as-of, and full-outer join stages.
- Moved renderer behavior behind explicit render artifacts and helper renderers for typed sinks, set operations, join indexes, parallel blocks, order records, and generated row access.
- Hardened evaluator runtime caches with bounded cache options and characterization coverage.
- Added typed unsupported-expression conversion paths and semantic traversal frame support.
- Expanded evaluator architecture and generated-code guardrails for runtime-v2 maintainability.

## Compatibility

Only `Musoq.Evaluator` is released as `17.0.1-alpha.1`. Other Musoq packages remain on their existing `17.0.0-alpha.7` versions.

# Musoq.Evaluator 17.0.4-alpha.4 - Generic Positional Row Binding

This package-specific alpha fixes a generated-execution regression where schema-indexed `object[]` fields could lose positional access after CTE materialization and set-operation lowering.

This prerelease is for:

- `Musoq.Evaluator`

## Highlights

- Preserved indexed field access through materialized CTE row carriers while retaining the complete source row, including payload fields that are not part of a final set-operation key.
- Centralized metadata-preserving rebinding for typed and untyped stored row transitions so field access strategies follow the current carrier representation.
- Added a target-neutral lowering invariant that rejects unresolved indexed bindings before a renderer can fall back to CLR member access.
- Covered `UNION`, `UNION ALL`, `INTERSECT`, `EXCEPT`, CTE fusion and materialization, sidecar indexes, filters, ordering, distinct, joins, permuted indexes, nullable values, nested cells, opaque names, and repeated compilation.

## Compatibility

This release does not change public APIs, SQL syntax, datasource row contracts, or renderer contracts. CLR-member, dictionary, dynamic, and unsupported-array source behavior remains covered by the existing controls.

# Musoq.Evaluator 17.0.1-alpha.2 - Runtime V2 Aggregate Snapshots

This package-specific alpha release publishes evaluator runtime-v2 aggregate rendering improvements and makes generated-code snapshots first-class review artifacts.

This prerelease is for:

- `Musoq.Evaluator`

## Highlights

- Optimized runtime-v2 chunked parallel aggregation with generated chunk workers, local shard loops, and fused aggregate result emission for weather-style single aggregate workloads.
- Added focused converter and evaluator coverage for aggregate fusion, strict casts, chunked parallel aggregation, and generated-code shape budgets.
- Added weather-measurement schema fixtures and benchmark coverage for runtime-v2 aggregate fast paths.
- Tracked the generated-code sample corpus under `generated-code-samples/current/` and `generated-code-samples/profiled/` so generator changes produce normal Git diffs.
- Tightened generated-code snapshot tests so missing tracked sample directories or files fail explicitly.

## Compatibility

Only `Musoq.Evaluator` is released as `17.0.1-alpha.2`. Other Musoq packages remain on their existing `17.0.0-alpha.7` versions.

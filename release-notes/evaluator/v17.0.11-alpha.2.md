# Musoq.Evaluator 17.0.11-alpha.2 - Query-Scoped Source Diagnostics and Generated Rows

This package-specific alpha improves source-contract validation during compilation and preserves generated row shapes through join and window lowering.

This prerelease is for:

- Musoq.Evaluator

## Highlights

- Reject a source at compile time with MQ3071 when it advertises QueryScopedRows but the runtime schema returned during description does not implement IQueryScopedRowSourceSchema.
- Preserve diagnostics returned by source description and retain the runtime guard for capability mismatches that appear only during execution.
- Propagate generated row shapes from values and query-scoped sources through join and window lowering, keeping generated-row buffers available to direct-index rendering.

## Compatibility

This package does not intentionally change the public Musoq.Evaluator API or datasource-provider contracts. Use the matching Musoq.Converter 17.0.11-alpha.2 package when compiling queries. The complete Core package set is aligned at 17.0.11-alpha.2.

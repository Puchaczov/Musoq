# Musoq.Evaluator 17.0.9-alpha.2 - Source Shape and Join Advisory Fixes

This package-specific alpha fixes two runtime-v2 regressions in `Musoq.Evaluator`:

- dynamic-source self-joins could fail compiled-artifact packaging when distinct fields advertised the same physical schema index;
- valid `CROSS JOIN` and uncorrelated derived `CROSS APPLY`/`OUTER APPLY` operations could emit the false `MQ5010` tautological-predicate advisory.

This prerelease is for:

- `Musoq.Evaluator`

## Highlights

- Assigned each source shape a dense, local `FieldBinding.OutputIndex` while preserving the original schema `ColumnIndex` for positional reads.
- Preserved source names, qualified aliases, dictionary keys, and projected/reordered field semantics.
- Kept strict target ABI duplicate-index validation unchanged and added coverage for repeated physical indices, sparse indices, reordered fields, and aliased dynamic self-joins.
- Centralized join-predicate advisory analysis across all supported join-node variants and skipped analysis only for `JoinType.Cross`.
- Preserved explicit `INNER JOIN ... ON true` `MQ5010` diagnostics.
- Preserved uncorrelated derived APPLY nodes instead of rewriting them into synthetic always-true joins.

## Compatibility

This release does not intentionally change the public `Musoq.Evaluator` API, SQL execution semantics, or datasource contracts. Parser, Plugins, and Schema remain at `17.0.9-alpha.1`. Use the matching `Musoq.Converter` `17.0.9-alpha.2` package when compiling and loading artifacts because Converter resolves the Evaluator dependency by exact package version.

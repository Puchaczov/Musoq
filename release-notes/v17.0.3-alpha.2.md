# Musoq 17.0.3-alpha.2 - DESC Dispatch Fix

This full-train alpha fixes a runtime-v2 metadata dispatch regression introduced in `17.0.3-alpha.1`.

This prerelease publishes:

- `Musoq.Parser`
- `Musoq.Plugins`
- `Musoq.Schema`
- `Musoq.Evaluator`
- `Musoq.Converter`

## Highlights

- Fixed root `DESC #schema` and `DESC FUNCTIONS #schema` so schema enumeration does not call `GetRawConstructors("", metadataContext)`.
- Preserved concrete method binding for `DESC #schema.method`, `DESC #schema.method()`, column descriptions, `DESC SETTINGS`, `DESC QUERY`, and ordinary datasource paths.
- Added a dispatch-matrix integration suite with a probe schema that rejects empty-name filtered constructor lookups.

## Compatibility

No public API changes. Existing positional and named datasource argument behavior remains unchanged, and `DESC` method-specific overload resolution continues to use the requested method name.

## Release verification

Release verification passed with 16,779 total tests: 16,775 passed, 4 skipped, and 0 failed. The five registered packages are validated through Release packaging and package smoke tests.

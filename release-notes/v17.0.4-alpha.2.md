# Musoq 17.0.4-alpha.2 - Schema-indexed positional datasource compatibility

This full-train alpha restores generated-execution compatibility for schema-driven datasource rows represented as one-dimensional `object[]` values while preserving the engine's reflection-free execution boundary.

This release publishes:

- `Musoq.Parser`
- `Musoq.Plugins`
- `Musoq.Schema`
- `Musoq.Evaluator`
- `Musoq.Converter`

## Highlights

- Added a shared schema-indexed row contract whose first supported carrier is exactly one-dimensional `object[]`.
- Bound projected columns directly to their schema indexes, so runtime-defined rows do not need generated CLR members, dictionary adapters, copying, or per-read reflection.
- Treated column names as opaque metadata when bracketed, including punctuation-heavy names such as `[%$@%T@sas$@#$]` and dotted names such as `[Address.City]`.
- Preserved ordinary nested syntax: `row.Address.City` traverses the typed value stored at the `Address` index instead of being flattened into a dotted column name.
- Covered direct projections, `SELECT *`, predicates, ordering, grouping, aggregates, CTEs, joins, nulls, reordered indexes, repeated compilation, and `Count(string)` datasource usage.

## Compatibility boundary

- Public typed CLR rows remain the preferred contract for fixed schemas.
- Direct positional `object[]` rows are supported for runtime-defined schemas.
- Supported `IDictionary<string, object>` rows and `ExpandoObject` remain the preferred contract for flexible name-based access.
- Generated reflection fallback is not introduced.
- `object`, inaccessible CLR entities, custom dynamic objects, `object[][]`, arbitrary lists, negative indexes, and inaccessible projected cell types remain unsupported and report MQ3084 or the applicable binding diagnostic.

## Diagnostics and documentation

MQ3084 guidance now includes “schema-indexed positional row, currently `object[]`” alongside public CLR and dictionary/`ExpandoObject` contracts. Evaluator performance documentation defines the contract selection and structural generated-code guardrails.

# Musoq.Plugins 17.0.11-alpha.2 - Deterministic Clock Access

This package routes current local and UTC date reads through internal clock accessors for deterministic testing.

This prerelease is for:

- Musoq.Plugins

## Highlights

- `GetDate` and `UtcGetDate` now use internal virtual accessors that tests can override.
- The default accessors still return `DateTimeOffset.Now` and `DateTimeOffset.UtcNow`.

## Compatibility

No public API or default date behavior change is intended. Use this package with the matching 17.0.11-alpha.2 Core packages.

## Manual impact

This plugins package does not change CLI commands, service behavior, supported tool endpoints, MCP resources, or installer behavior. Manual impact is unchanged.

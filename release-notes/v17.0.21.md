# Musoq Core Engine 17.0.21

Stable patch release of seven aligned .NET 10 packages: Musoq.Parser,
Musoq.Plugins, Musoq.Schema, Musoq.Evaluator, Musoq.Converter, Musoq.Formatter,
and Musoq.Benchmarks.Scenarios. Upgrade engine packages together.

## Query execution improvements

- Use vectorized masks for eligible numeric filters over materialized CTE columns, reduce eligible integral extrema directly, and share reusable unfiltered window inputs.
- Reduce repeated work in correlated quantified subqueries, full outer inequality joins, bounded numeric RANGE windows, and bounded `ROW_NUMBER ... QUALIFY` queries.
- Improve eligible filtered projections, bounded ordering, deep `SKIP`, and global `COUNT(*)` while preserving source order, cancellation, query lifetime, and error behavior.
- Reduce repeated datasource warning binding and improve eligible byte interpretation and delimited-text parsing paths while preserving diagnostics and SQL null behavior.

The changes add opt-in Local workloads and regression coverage. The fixed Official
benchmark catalog remains at 279 cases.

## Compatibility and downstream impact

No intentional public datasource API, SQL syntax, Execution IR, host ABI, or
persisted-query format change is included. Stable packing validates
Musoq.Schema and Musoq.Plugins against the greatest published lower same-major
ABI baseline. No datasource migration is required.

The Release solution build passed with zero warnings or errors. The full suite

# Musoq 17.0.14-alpha.2

This correctness release publishes Musoq.Parser, Musoq.Plugins, Musoq.Schema,
Musoq.Evaluator, and Musoq.Converter together at 17.0.14-alpha.2.

## Correctness fixes

- Residual `NOT LIKE '%'` compiles and matches the provider-enabled result: null
  and missing values satisfy NOT LIKE, while empty and non-empty strings satisfy LIKE.
- Negotiated constant RLIKE and NOT RLIKE predicates carry the effective regex
  timeout for their compilation, including custom budgets. Accepted-predicate
  matching uses the same budget and leaves only rejected predicates residual.
- Public .NET `RegexMatchTimeoutException` causes at datasource lifecycle boundaries
  produce MQ7017 and retain their typed cause and actual budget. Ordinary source
  failures keep their existing diagnostics; safe diagnostic output omits input and pattern text.
- Equality self-correlation keeps generated CTE projection names out of physical
  source metadata requests. General correlation reuses equivalent generated
  query-row declarations within the containing class while retaining independent source bindings.

## Compatibility and boundaries

- No public provider API or ABI changes from 17.0.14-alpha.1. Predicate capability
  contract version 2 is unchanged. Providers can continue using the public .NET
  regex exception without referencing Evaluator or constructing internal exceptions.
- Upgrade the five Core packages together. Unicode LIKE transfer restrictions,
  unsupported wildcard shapes, and conservative correlated-regex transfer boundaries remain unchanged.
- The existing alpha packaging policy skips the Schema/Plugins datasource ABI
  baseline gate; no intentional ABI break is introduced by this release.
- DataSources integration qualification and any downstream dependency/manual refresh
  remain work for those repositories. This release changes only Core.

## Validation

Core regressions cover capability-enabled, capability-disabled, and provider-rejected
execution; null/missing strings; default/custom regex budgets and isolation;
public provider timeouts; repeated and concurrent self-correlation; and mixed native/query-scoped sources.

- Release solution build: zero warnings and errors.
- Full Release solution suite: 29,171 passed, zero failed, four existing generated-sample refresh skips across nine test assemblies.
- Broader focused evaluator regressions: 709 passed. The final 26 release-specific regressions also passed after strengthening the overlap synchronization.
- Release-script tests, release-tag validation, five-package packing, and package smoke tests passed.
- Before the fixes, Core tests reproduced CS0023 for residual negation, the default two-second provider budget despite custom options, MQ7011 for public regex timeouts, unknown `_sq_1_key` metadata, and duplicate query-row declarations.

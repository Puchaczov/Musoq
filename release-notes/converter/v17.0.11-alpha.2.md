# Musoq.Converter 17.0.11-alpha.2 - Generated Row Rendering

This package-specific alpha ships the generated-row rendering fix in the bundled C# target and aligns Converter with Musoq.Evaluator 17.0.11-alpha.2.

This prerelease is for:

- Musoq.Converter

## Highlights

- Allow direct-index rendering when an execution variable carries a generated row type name, while continuing to reject untyped object rows and preserve ExpandoAdapter support.
- Propagate generated row shapes through values and query-scoped sources in join and window lowering so filtered joins retain generated-row buffers.
- Resolve the matching Musoq.Evaluator 17.0.11-alpha.2 package dependency.

## Compatibility

This package does not intentionally change the public Musoq.Converter API or artifact format. Use it with Musoq.Evaluator 17.0.11-alpha.2 and the matching Parser, Plugins, and Schema packages. The complete Core package set is aligned at 17.0.11-alpha.2.

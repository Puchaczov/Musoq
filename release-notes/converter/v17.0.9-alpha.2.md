# Musoq.Converter 17.0.9-alpha.2 - Artifact Packaging Compatibility

This package-specific alpha is released with `Musoq.Evaluator` `17.0.9-alpha.2` so Converter consumers receive the corrected evaluator implementation for dynamic-source compiled artifacts.

This prerelease is for:

- `Musoq.Converter`

## Highlights

- Aligns the Converter package dependency with `Musoq.Evaluator` `17.0.9-alpha.2`.
- Covers deterministic dynamic-source self-joins with repeated physical schema indices through artifact compilation, loading, execution, and direct-result equivalence.
- Verifies source ABI indices are dense and unique while aliases, qualified names, dictionary keys, and positional metadata remain correct.

# Musoq.Converter 17.0.3-alpha.3 - Explicit Artifact Render Context

This package-specific alpha release makes reusable compiled-artifact rendering assumptions explicit and aligns strict validation with compilation.

This prerelease is for:

- `Musoq.Converter`

## Highlights

- Added an explicit contextual-execution property to the converter build context instead of relying on raw build-item dictionary access.
- Centralized reusable-artifact rendering configuration so artifact compilation and strict validation use the same render context.
- Ensured strict artifact validation regenerates artifacts under the contextual execution assumptions used by the original compilation.
- Added compatibility and end-to-end tests for render-context propagation, strict validation, and execution compilation-cache behavior.
- Separated evaluator compilation benchmarks so artifact and execution compilation costs remain independently measurable.

## Compatibility

This release does not intentionally change the public `Musoq.Converter` API. `Musoq.Converter` is released as `17.0.3-alpha.3`; Parser, Plugins, and Schema remain at `17.0.3-alpha.2`. It is intended to be used with the separately released `Musoq.Evaluator` `17.0.3-alpha.3` package.

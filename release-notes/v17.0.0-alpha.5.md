# Musoq 17.0.0-alpha.5 - Runtime V2 Profiling Seams

This alpha release adds host-facing runtime-v2 profiling and explain-analyze seams used by CLI and local-agent execution flows. It keeps the existing SQL diagnostic commands intact while exposing reusable APIs so hosts do not need to copy parser or execution-plan logic.

This is a full-train prerelease for:

- `Musoq.Parser`
- `Musoq.Plugins`
- `Musoq.Schema`
- `Musoq.Evaluator`
- `Musoq.Converter`

## Highlights

- Made the diagnostic SQL command classifier public through `DiagnosticSqlCommandParser`, `DiagnosticSqlCommand`, and `DiagnosticSqlCommandKind`.
- Added bindable `CompileForExplainAnalyze(...)` APIs that expose `Parameters`, `ParameterDefinitions`, `RequiredParameters`, and `ParameterContracts` before running explain-analyze.
- Added `CompiledExplainAnalyzeQuery`, allowing hosts to bind runtime parameters and then call `Run(CancellationToken)`.
- Preserved existing `PROFILE ...` and `EXPLAIN ANALYZE ...` SQL command behavior: diagnostic commands still return their diagnostics text table as ordinary query output.
- Added coverage for diagnostic command classification, parameter-bound explain-analyze, and cancellation before and during explain-analyze execution.

## Compatibility

Existing `InstanceCreator.ExplainAnalyze(...)` callers are compatible. Hosts that need runtime parameter binding before explain-analyze execution should switch to `CompileForExplainAnalyze(...)`.

# Musoq Core Engine 17.0.23

Stable patch release for .NET 10. Upgrade Musoq.Parser, Musoq.Plugins,
Musoq.Schema, Musoq.Evaluator, Musoq.Converter, Musoq.Formatter, and
Musoq.Benchmarks.Scenarios together.

## SQL query results

- Accept infix NOT BETWEEN, CTE output lists adjacent to the CTE name,
  and logical expressions in CASE result branches. Bind ranges, patterns,
  shifts, membership, mixed numeric comparisons, and scalar subqueries using
  the operand types required by each operation.
- Preserve projected and hidden grouping and ordering keys, NULLs and
  duplicate rows across joins, sets and CTEs. Keep materialized results
  separate when sibling subqueries use CTEs, preserve scalar subquery
  cardinality during expression lowering, and bind applicable nullable
  generic datasource overloads.
- Clamp window frames to their partitions, resolve RANGE offsets in the
  ordering key’s numeric domain, and number scalar rows after sorting and
  before paging. Preserve aggregate filters and empty-group results.

## Interpretation and execution

- Preserve declared binary and text field types, nullability, cursor
  behavior, and partial results through record access, APPLY, and other
  relational operators. Datasource providers can expose safe field
  conversion details for diagnostics.
- Locate the start of a backward ASOF tie group with binary search while
  preserving stable ordering and explicit tie-break expressions.
- Reuse strict decoders for standard binary encodings and retain custom
  encoding behavior. Pre-size fixed-width arrays when the input proves
  they fit, and avoid copies when a binary payload is discarded or only
  its length is required.
- Traverse native record collections by index and use smaller initial
  buffers for short iterators. Datasource providers can opt into per-record
  APPLY processing with `ApplyRows.Stream`. Existing iterators keep their
  read-ahead and disposal behavior.

## Compatibility and qualification

The stable packer validates Musoq.Schema and Musoq.Plugins against the
published 17.0.22 datasource ABI. This release keeps the Execution IR, host
ABI, and persisted query format versions. The Core specification family
drops the AI interpretation proposal from its optional profiles.

The [diagnostic migration guide](../docs/diagnostic-migration-v17-v18.md)
records the earlier changes to the host diagnostic surface. Downstream
manuals that mirror Core specifications should refresh their imported
documentation when they adopt 17.0.23.

Release qualification uses the full Release test suite, package validation,
and Windows and Linux CI for the tagged source. The pre-release feature
qualification passed 32,513 automated tests with four manual refresh skips.
The Official 17.0.23 benchmark campaign follows publication and integration.

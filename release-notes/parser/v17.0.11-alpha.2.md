# Musoq.Parser 17.0.11-alpha.2 - Runtime Input Diagnostics

This package adds structured diagnostics for malformed runtime input and interpretation failures.

This prerelease is for:

- Musoq.Parser

## Highlights

- Added MQ7014 for malformed runtime input and MQ7101-MQ7115 for specific interpretation failures.
- Added typed runtime-input failure reasons and locations, including line, column, byte offset, and character offset, separately from SQL source locations.
- Added safe diagnostic conversion and metadata so provider-owned input text is not exposed in ordinary diagnostic messages.

## Compatibility

This alpha adds public diagnostic types and members. Pair it with Musoq.Schema 17.0.11-alpha.2 for structured runtime-input diagnostics. No SQL grammar or datasource-provider interface change is intended.

## Manual impact

This parser package does not change CLI commands, service behavior, supported tool endpoints, MCP resources, or installer behavior. Manual impact is unchanged.

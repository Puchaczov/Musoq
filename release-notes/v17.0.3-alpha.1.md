# Musoq 17.0.3-alpha.1 - Recursive Execution and Runtime-v2 Completion

This full-train alpha consolidates the recursive query execution, runtime-v2 architecture, and named datasource invocation work completed on `feature/runtime_v2_final`.

This prerelease is for:

- `Musoq.Parser`
- `Musoq.Plugins`
- `Musoq.Schema`
- `Musoq.Evaluator`
- `Musoq.Converter`

## Highlights

- Added contextual `WITH RECURSIVE`, CTE column lists, recursive shape validation, recursive logical and physical plans, and keyed or full-row recursive `UNION` identity.
- Added breadth-first semi-naive recursive execution with typed frontier rows, invariant snapshots, direct reusable indexes, cancellation, independently configurable row/iteration/snapshot limits, and recursive plan and profile inspection.
- Added recursive CTE source traversal and composition across joins, APPLY, ordinary CTEs, projections, filters, aggregates, windows, set operators, nullable values, and column-liveness pruning.
- Added generated-code, integration, graph-fixture, profiling, handwritten-baseline, and performance coverage for supported and rejected recursive query shapes.
- Completed runtime-v2 ownership boundaries across semantic coordination, portable execution IR, physical lowering, target-neutral execution, CSharp CLR rendering, and execution dispatch.
- Added immutable execution-artifact handoffs, per-run runtime state isolation, true asynchronous row execution, deferred-result lifetime leasing, generated assembly ownership, Roslyn lifetime scoping, and bounded type/metadata/runtime caches.
- Added named datasource argument syntax and compile-time binding with case-insensitive names, optional reflected defaults, deterministic overload diagnostics, canonical invocation vectors, and parity across direct, coupled, APPLY, and `DESC` source surfaces.
- Preserved positional datasource overload resolution, public `Musoq.Schema` compatibility, diagnostic exception taxonomy, and explicit unsupported-source diagnostics.
- Hardened parser contextual-keyword behavior, statement recovery, generated-code shape contracts, architecture ratchets, documentation contracts, and release guardrails.

## Compatibility

Existing supported query and datasource forms remain compatible. Recursive CTEs use contextual syntax and retain the documented supported-shape boundaries; keyed recursive identity binds to exported column names, and configured runtime limits remain hard ceilings. Named datasource arguments are additive, while positional invocation and existing public schema contracts remain supported. `Musoq.Targets.CSharpClr` continues to ship bundled through `Musoq.Converter` rather than as a standalone package.

`Musoq.Schema` and `Musoq.Plugins` remain protected by same-major datasource ABI validation during packaging.

## Release verification

Release verification passed with 16,772 total tests: 16,768 passed, 4 skipped, and 0 failed. The five registered packages are validated through Release packaging and package smoke tests.

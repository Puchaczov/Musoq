# Musoq Core Engine 17.0.17

Musoq Core Engine 17.0.17 is a stable release of seven aligned .NET 10 packages:
Musoq.Parser, Musoq.Plugins, Musoq.Schema, Musoq.Evaluator, Musoq.Converter,
Musoq.Formatter, and Musoq.Benchmarks.Scenarios. Upgrade engine packages together.

## Query planning and execution

Opt-in computed source projections now carry typed expressions through planning,
source shapes, physical execution, rendering, cache identities, and artifact metadata.
Planner-owned eligibility checks and strict accepted/residual contracts preserve
ordinary source behavior when the capability is not supported.

Interpretation uses prepared text patterns, status-based parsing, compact completion
tracking, and executable reuse with identities that include generated source and
runtime contracts. Terminal results avoid redundant row materialization, and accepted
computed projections omit provider-only inputs from their row carriers.

Shared byte-buffer planning propagates demands through aliases, projections, and
private CTEs. Bounded snapshots, concatenation, and private views are represented in
Execution IR while preserving evaluation effects, ownership, null and empty values,
allocation identity, and invalid-input and overflow fallbacks. Public and opaque
boundaries retain complete values.

Exact compilation-cache hits retain executable build receipts used by inspection.

## Regression coverage and development quality

Converter and Plugins regression suites are split into focused projects with shared
typed fixtures. Independent result oracles cover ordering, paging, joins, expressions,
and conversions. Culture isolation, generated-code inspection, contention coordination,
and native-row assertions strengthen deterministic verification.

CSharpier 1.3.0 provides consistent authored C# and MSBuild formatting with CI checks.
Generated samples, imported fixtures, historical benchmarks, and embedded literal
values are preserved by the formatting policy.

## Benchmarks

Representative coverage includes computed projections, source boundaries, scans,
joins, grouping, windows, and interpretation. Campaigns preserve deterministic
fixtures, independent expected results, raw attempts, and source/runtime provenance.
Lifecycle metadata supports active and retired cases without rewriting history.
The release qualification records a full Official campaign on the tagged source.
Individual timings and allocations are reported without an aggregate speedup claim.

## Compatibility

The release retains the supported datasource binary contracts. Stable packing requires
Musoq.Schema and Musoq.Plugins compatibility validation against the greatest published
lower same-major package versions. Default source capabilities remain unchanged.
Execution IR is version 14 and host ABI is version 10; package format remains version 2.
Recompile persisted query artifacts when upgrading the engine.

## Release qualification

Publication requires formatting and release-tooling checks, the Release solution build
and full tests, validated package archives, and successful Linux and Windows push CI
for the exact release commit. The Official benchmark campaign must complete and pass
structural and provenance verification before tagging. Publication is verified through
the stable GitHub Release assets and exact NuGet package versions and payloads.

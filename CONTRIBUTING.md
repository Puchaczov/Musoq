# Feedback and contributions

I welcome bug reports, documentation feedback, feature ideas, and questions. I accept pull requests only from repository collaborators.

## Report a bug or documentation problem

Open a [GitHub issue](https://github.com/Puchaczov/Musoq/issues). For a bug, include the Musoq version, a minimal query or steps that reproduce it, any sample input needed, and what you expected to happen. Describe what actually happened and include the error message if there is one.

For a documentation problem, link to the page and point out the passage that needs attention.

## Share an idea or ask a question

Share feature ideas in [Ideas](https://github.com/Puchaczov/Musoq/discussions/categories/ideas). Describe what you are trying to do and where the current behavior falls short. Ask questions about using Musoq in [Q&A](https://github.com/Puchaczov/Musoq/discussions/categories/q-a).
